# GPS Live Location (Android ایپ)

کیمرہ + GPS ایپ: تصویر کھینچیں اور نیچے خود بخود Latitude / Longitude / پتہ / تاریخ و وقت کا پیڈ لگ جاتا ہے۔

## ایپ میں کیا ہے

- **Live** موڈ: فون کا GPS خود لوکیشن دیتا ہے (درستگی اور اونچائی بھی نظر آتی ہے)
- **Manual** موڈ: آپ خود Latitude اور Longitude لکھیں، **Set** دبائیں، اسی لوکیشن کا پیڈ تصویر پر لگے گا
- تصویر Gallery میں **Pictures/GPS Live Location** فولڈر میں محفوظ ہوتی ہے (GPS EXIF کے ساتھ)
- ایپ کے اندر **Gallery** بٹن: محفوظ تصویریں دیکھیں، Share کریں یا Delete کریں
- **Copy** (کوآرڈینیٹس کاپی) اور **Maps** (گوگل میپس میں کھولیں)
- **Flip**: آگے/پیچھے کا کیمرہ بدلیں
- ضرورت: Android 10 یا اس سے نیا

## APK بنانے کے دو طریقے

### طریقہ 1: GitHub سے (کمپیوٹر پر کچھ انسٹال کیے بغیر)

1. github.com پر مفت اکاؤنٹ بنائیں اور نئی repository بنائیں۔
2. اس پراجیکٹ کی تمام فائلیں اور فولڈر اپ لوڈ کریں۔ اگر `.github` فولڈر اپ لوڈ نہ ہو تو **Add file → Create new file** میں نام `.github/workflows/build-apk.yml` لکھ کر اسی نام کی فائل کا مواد پیسٹ کر دیں۔
3. repository کے **Actions** ٹیب میں **Build APK** کھولیں، **Run workflow** دبائیں (چند منٹ لگتے ہیں)۔
4. مکمل ہونے پر اسی صفحے سے **GPS-Live-Location-APK** ڈاؤن لوڈ کریں، زپ کھولیں، اندر `app-debug.apk` ہے۔
5. APK فون میں بھیجیں اور کھولیں۔ جب فون پوچھے تو "نامعلوم ذرائع سے انسٹال" کی اجازت دے دیں۔

### طریقہ 2: Android Studio سے

1. Android Studio میں **Open** کر کے یہ فولڈر منتخب کریں اور Gradle sync مکمل ہونے دیں۔
2. **Build → Build APK(s)** دبائیں۔ فائل یہاں بنے گی: `app/build/outputs/apk/debug/app-debug.apk`
3. یا فون کو USB سے جوڑ کر (USB debugging آن کر کے) سیدھا **Run** دبائیں۔

## پہلی بار کھولنے پر

ایپ کیمرہ اور لوکیشن کی اجازت مانگے گی، دونوں **Allow** کریں۔ Live موڈ کے لیے فون کی Location (GPS) آن ہونی چاہیے۔ پتہ (address) دکھانے کے لیے انٹرنیٹ چاہیے، باقی سب کچھ بغیر انٹرنیٹ بھی چلتا ہے۔
